二、为什么需要这些模块

模块 去掉/换掉会怎样 所以它解决什么
stack（留住历史） 标准残差只留一个 partial，历史一旦被加总就取不回来 让「更早的层」在后续层里仍然可寻址，而不是被稀释进一个和
RMSNorm（只给打分用） 不做归一化，模长大的层靠幅值就能占满 softmax 让权重由方向决定而非幅值；且混合仍用原值，保住各层真实尺度
W／伪查询 w_l 换成固定 1 → 退回标准残差；换成静态标量 → 就是 DenseFormer，几乎无收益 权重逐层、逐 token 自适应；w_l 不带 token 维，所以同块内可批量预算
softmax（在来源维） 用线性权重就不成其为「检索」，只算加权平均 制造竞争：想多读某一层，必须少读别层，权重总量守恒
einsum 取回 没有它，层只能看「上一层压缩过的状态」 这一层的输入 = 按需重组的历史，而不是唯一的累加和
块边界入栈（Block 版） Full 版要留住全部 LLL 层输出，每 token O(Ld)O(Ld)O(Ld) 状态从 O(Ld)O(Ld)O(Ld) 降到 O(Nd)O(Nd)O(Nd)：块内仍等权，只在块间检索

一句话：朴素残差的问题是「历史只累加、不可检索」，这五步分别负责「留住历史、让权重可比、让权重可学、让权重竞争、把历史取回来」。

与 mHC 那类方法正交：mHC 加宽「当前状态」（多条残差流），AttnRes 检索「过去」（深度维 attention）。代价是每 token 多存 N+1N+1N+1 份 ddd 维向量、每层多一次 n+1n+1n+1 路的 softmax，K3 上约 2% 推理开销。
